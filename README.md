# homebrew-jwks-bridge

Homebrew tap for [jwks-bridge](https://github.com/bcollard/jwt-signer-vault-jwks-bridge): serve Vault-stored signing keys to the Kong jwt-signer plugin and a public JWKS to backends.

```sh
brew tap bcollard/jwks-bridge
brew install --cask jwks-bridge
```

The cask in `Casks/` is published by GoReleaser on each release.
